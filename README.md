## What is it ?

It's a real-time room-based sprint poker system. Was tired a freemium found on internet before each sprint planning, so I decided to create mine.

Stack :

- Frontend : NuxtJS
- Backend : .NET 10 / EF Core / Clean Architecture + Modular Monolith (see PokyBack project for more infos, same repo)
- MySQL for db
- Hosted with Docker
- SignalR for websockets
